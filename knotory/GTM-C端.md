## 定价策略（C 端）

### 1. 本地版 · ¥0（永久）

- **含**：全功能自托管，数据本地
- **不含**：LLM API 费用（用户自备火山方舟等）
- **转化**：GitHub / 教程引流 → `/library` 上传第一篇

### 2. 早鸟支持者 · ¥68/年（推荐档）

- **含**：社群优先、路线图投票、内测资格
- **心理价**：低于一门网课单月，高于「请我喝杯咖啡」
- **履约**：微信群 + 更新日志；暂不接支付时可「登记等候名单」

### 3. Cloud 版 · 敬请期待

- **目标价**（规划）：¥29–49/月，含一定 LLM 额度 + 托管
- **作用**：锚定「免 Docker」需求，收集意向

### 定价原则

- 软件免费、**算力另计** —— 诚实，避免 API 账单纠纷
- 先 **社群 + 早鸟** 验证付费意愿，再上 Cloud
- 不做按闪卡张数计费（复杂且抑制使用）

## 社群运营

### 渠道

| 渠道 | 用途 |
|------|------|
| 微信早鸟群 | 答疑、API 配置、版本通知（≤200 人精细化） |
| GitHub Issues | Bug、功能请求 |
| 即刻 / 小红书 | 短内容：「PDF→闪卡」「Obsidian 第二遍」 |
| 邮件列表 | 等候名单 → 大版本推送 |

### 内容日历（建议）

- **周更**：1 篇「学习法 + 截图」（推荐流 / 复习页）
- **双周**：1 条配置教程（ARK_KEY、Docker）
- **发版**：CHANGELOG + 群公告

### 社群话术（入群欢迎）

> 欢迎来 Knotory 早鸟群。这里是「个人语料 → 闪卡 → 刷读」的实验场。
> ① 先 `/library` 上传一篇 PDF 或 md；② 等后台 sync 后刷首页推荐；③ 有问题带截图 @管理员。
> 数据在你本机，我们不收语料。
